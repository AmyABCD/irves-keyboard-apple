# 🐆 Ирвэс Гар (Irves Keyboard) - Apple хувилбар (iOS & macOS)

Орхон аймгийн Хүүхэд, Гэр бүлийн хөгжил, хамгааллын газрын **Ирвэс гарын товчлуур**-ыг Apple төхөөрөмжүүдэд (iPhone, iPad, MacBook, iMac) зориулан бүрэн хөгжүүлсэн багц.

---

## ✨ Онцлог боломжууд

1. **Монгол кирилл гарын бүрэн байрлал**: Стандарт кирилл (`фцужэнгшүзкъ...`) байрлал + Англи (QWERTY) + Тоо, тэмдэгтүүд (₮ тэмдэгт багтсан).
2. **Spacebar шударч хэл солих**: Зайны товчлуур (Space) дээр хуруугаараа зүүн/баруун тийш шударч (swipe) Монгол ба Англи хэлийг хялбар сэлгэнэ.
3. **54 Ирвэс Маскот стикерүүд**: Сэтгэл хөдлөл, мэргэжил, хүүхэд хамгаалал, гарын дохионы 54 ширхэг албан ёсны ирвэс стикерүүд. Товшиход түр санах ой (Clipboard) руу хуулагдаж Messenger, Instagram, Telegram, WhatsApp руу шууд наана (Paste).
4. **Стандарт Эможи (Unicode Emoji)**: Байнга ашиглагддаг стандарт эможины самбар.
5. **Дуу болон Чичиргээ (Haptic & Audio)**: Товч дарахад хүрэлцэх мэдрэмж (Taptic Engine) болон товшилтын дуу гарна.
6. **Dark / Light горим**: Утасны системийн загварыг (Dark/Light Mode) автоматаар дагана.
7. **macOS дэмжлэг**: Mac компьютерт зориулсан `.keylayout` системийн файл багтсан.

---

## 📱 iPhone / iPad дээр суулгах заавар

iOS үйлдлийн систем нь тусгай хамгаалалттай тул гар (Keyboard Extension)-ыг хоёр аргаар суулгаж болно:

### Арга 1: Windows компьютерээс Sideloadly ашиглан 1 минутанд суулгах (Хамгийн хялбар)
1. Компьютер дээрээ [Sideloadly](https://sideloadly.io/) програмыг татаж суулгана (Үнэгүй).
2. iPhone-оо компьютертэйгээ утсаар (USB) холбоно.
3. Sideloadly дээр `IrvesKeyboard.ipa` файлыг чирж тавина.
4. Өөрийн Apple ID (үнэгүй хувийн хаяг)-аа оруулаад **Start** дарна.
5. iPhone дээрээ **Settings -> General -> VPN & Device Management** цэснээс өөрийн Apple ID-гаа **Trust** (итгэмжлэх) дарна.

### Арга 2: Mac компьютертай бол (Xcode-оор шууд суулгах)
1. `IrvesKeyboard.xcodeproj` төслийг Xcode дээр нээнэ.
2. iPhone-оо холбоод дээд талын **Run (▶)** товчийг дарна.

---

### ⚙️ Утсан дээрээ Ирвэс гарыг идэвхжүүлэх (3-хан алхам):
1. iPhone-ийн **Settings (Тохиргоо) ➔ General (Ерөнхий) ➔ Keyboard (Гар) ➔ Keyboards (Гарууд)** руу орно.
2. **Add New Keyboard... (Шинэ гар нэмэх)** товчийг дараад жагсаалтаас **Ирвэс**-г сонгоно.
3. Нэмэгдсэн **Ирвэс** дээр дахин товшоод **Allow Full Access (Бүтэн эрх олгох)**-г асаана.  
   *(Энэ эрх нь чат руу стикер зураг хуулж оруулахад шаардлагатай бөгөөд таны шивсэн ямар нэг мэдээллийг гадагш дамжуулахгүй).*

---

## 💻 Mac (MacBook, iMac, Mac mini) дээр суулгах заавар

Mac компьютер дээр ямар нэгэн апп суулгахгүйгээр системийн түвшинд Монгол кирилл гарыг ашиглана:

1. **Finder** нээгээд дээд цэснээс **Go ➔ Go to Folder...** (эсвэл `Cmd + Shift + G`) товчийг дарна.
2. Дараах хаягийг хуулж бичээд Enter дарна:
   ```
   ~/Library/Keyboard Layouts/
   ```
3. Энэ хавтас руу `Irves_Mongolian.keylayout` файлыг хуулж тавина.
4. Компьютерийнхээ **System Settings ➔ Keyboard ➔ Text Input (Input Sources) ➔ Edit...** цэс рүү орно.
5. **+** товчийг дараад зүүн жагсаалтын хамгийн доод **Others** хэсгээс **Irves Mongolian**-г сонгоод **Add** дарна.
6. Таны Mac дээр стандарт Монгол гар бэлэн болох бөгөөд `Control + Space` товчоор хүссэн үедээ Англи/Монгол хооронд шилжинэ!
